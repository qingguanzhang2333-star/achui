# NEXABOT 官网

基于 Pencil 设计稿生成的 React + Tailwind CSS 实现。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 项目结构

- `src/components/` - 通用组件（Header、Hero、Features、Products、Stats、About、CTA、Footer）
- `src/pages/` - 页面组件（ProductDetail）
- `public/images/` - 静态图片资源

## 路由

- `/` - 首页
- `/products/nx-one` - NX-One 商品详情页
